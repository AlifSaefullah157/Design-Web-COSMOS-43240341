# COSMOS - Ensiklopedia & Observatorium Tata Surya

Platform web observatorium digital dan ensiklopedia astronomi interaktif modern yang menyajikan eksplorasi fotorealistik 8 planet tata surya, kalkulasi parameter astrometri presisi, simulasi orbit Kepler 3D interaktif real-time, dan modul evaluasi Kuis Kosmik komprehensif.

## 🎯 Nama dan Tujuan Proyek

**Nama Proyek:** COSMOS - Ensiklopedia & Observatorium Tata Surya

**Tujuan Proyek:**
1. **Mengatasi Keterbatasan Edukasi Sains Antariksa 2D Konvensional:** Menggantikan representasi buku teks statis dengan visualisasi interaktif tiga dimensi dan telemetri langsung agar pemahaman konsep mekanika orbit menjadi intuitif.
2. **Menyediakan Alternatif Software Laboratorium Tanpa Biaya Lisensi (Zero-Cost & Zero-Install):** Menghadirkan portal observatorium berbasis web murni yang dapat diakses secara instan dari peramban tanpa memerlukan spesifikasi perangkat keras khusus atau lisensi perangkat lunak berbayar yang mahal.
3. **Menyajikan Data Astrodinamika Terverifikasi 100%:** Menyediakan parameter ilmiah yang akurat sesuai standar astrometri mutakhir (IAU/NASA), mencakup satuan jarak AU, kilometer, kecepatan orbit Keplerian, inklinasi kemiringan sumbu, rasio diameter terhadap Bumi, dan temperatur permukaan ekstrem.
4. **Menerapkan Rekayasa Web Berstandar Industri:** Membuktikan integrasi menyeluruh dari alur perancangan konsep awal (Google Stitch), perancangan sistem desain presisi (Figma), hingga implementasi kode web murni (HTML5 Semantik, Modern CSS3 Flexbox & Grid, dan Vanilla JavaScript ES6+).

---

## 👥 Sasaran Pengguna (Target Audience)

Platform ini dirancang khusus untuk ekosistem pendidikan dan riset sains antariksa (*EdTech & Aerospace Science Communication*):
* **Edukator, Guru & Dosen Fisika/Astronomi:** Digunakan sebagai media peraga interaktif ruang kelas dan laboratorium untuk menjelaskan hukum Kepler dan karakteristik tata surya.
* **Pemandu & Kurator Planetarium/Museum Sains:** Digunakan pada anjungan digital (*interactive exhibit kiosk*) bagi pengunjung pameran astronomi.
* **Mahasiswa & Pelajar Jenjang Menengah Akhir/STEM:** Sebagai media belajar mandiri, telaah data komparatif antar-planet, dan pengujian pemahaman lewat modul Kuis Kosmik.
* **Komunitas Astronom Amatir & Pengamat Langit:** Sebagai panduan komparasi data posisi, jarak radial, dan parameter fisik objek tata surya.

* **Rentang Usia Pengguna:** 16 – 45 Tahun (Tingkat literasi teknologi menengah hingga mahir).
* **Kompatibilitas Perangkat:** Desktop Workstation & PC Kantor (1440x900 px), Laptop Edukasi, Tablet Interaktif (768 px), dan Smartphone Lapangan (360x800 px).

Masuk Akun (Login Gateway)** | • Kotak pembungkus form glassmorphism terstandarisasi (Width: 440–460 px, Min-Height: 580–600 px).<br>• Input Identitas Penjelajah (Email) & Kata Sandi terenkripsi.<br>• Tombol intip sandi (toggle visibility) & tautan pemulihan sandi.<br>• Validasi formulir instan dengan animasi pengautentikasian. |

Pendaftaran Akun (Register Explorer)** | • Dimensi kartu seragam persis dengan kartu Login (Zero Layout Shift).<br>• Input Nama Lengkap Penjelajah, Email Transmisi, dan Kata Sandi.<br>• Checkbox persetujuan Protokol Keamanan Antariksa & Privasi data.<br>• Tombol inisiasi akun kru dan tautan balik ke halaman Masuk. |

Beranda Observatorium (Home Observatory)** | • Bola planet 3D fotorealistik yang berputar terus-menerus mengelilingi sumbunya.<br>• Dedicated Planet Changer Bar (tombol Prev, Next, dan Acak/Shuffle planet).<br>• Panel telemetri aktif heliosentris (Jarak AU, waktu orbit, radius kilometer).<br>• Tombol pintas eksplorasi detail katalog dan peluncuran simulasi orbit. |

Misi Sabuk Asteroid (Asteroid Mini Game)** | • Mini game navigasi pesawat penjelajah melintasi sabuk asteroid.<br>• Kontrol gerakan responsif, pengumpulan kristal energi, aktivasi perisai pelindung, dan mode Hyper-Warp.<br>• Efek suara Web Audio API sintetis prosedural murni tanpa file audio eksternal.<br>• Perekaman skor terbaik otomatis ke localStorage. |

Fitur Visual Global Kosmik** | • Latar belakang kanvas bintang interaktif dengan 160+ bintang berkedip dinamis.<br>• Animasi meteor/bintang jatuh bercahaya meluncur secara diagonal.<br>• Respons kursor paralaks lembut dan percikan debu kosmik saat layar diklik.<br>• Bilah navigasi adaptif (Docking melayang di desktop, Sticky bar di ponsel). |
